## Terence Lewis

📍 **London, England • Remote / International**

I design and build safety-first, failure-aware systems for real-world platforms where dropped connections, partial failures, stale commands, and human error are expected, not ignored.

- **Aurora Logistical Eco Holdings Limited** — UK technology company building apps, websites, custom software, digital systems, and research infrastructure.
- **Code Strategy Solutions** — software strategy and development framework for practical coding systems and reusable technical patterns.
- **Bridge IT** — learning and systems-development framework connecting research ideas, software practice, and public-facing technical products.
- **WaterFallsLT** — public research, writing, media identity, GitHub-linked experiments, and technical publishing.

## Flagship work

### CabinApp
Full-stack private cabin stay platform with customer booking, owner/admin dashboard, backend APIs, database logic, automation, and internal tools.

### Harness
Safety-first control and mesh-style networking platform focused on formal state machines, command ageing, heartbeats, watchdogs, authority arbitration, kill paths, safe-state degradation, replayable command streams, and post-mortem analysis.
